# FaissImputer 0.2.0 benchmark

## Summary

- With complete training donors, FaissImputer and KNNImputer produced exactly matching values on all controlled continuous-data trials.
- With 20,000 training rows, FaissImputer transform was 19.62 times faster for one shared missingness pattern and 10.78 times faster for eight patterns.
- With 294 patterns among 300 test rows, FaissImputer and KNNImputer were effectively tied at 342.83 ms and 340.93 ms.
- With 10% missing training cells, native KNNImputer achieved RMSE 0.2440 and FaissImputer achieved 0.3495 because version 0.2.0 uses only fully observed donor rows.

These results describe this synthetic dataset, environment, and configuration. They are not a general guarantee that FaissImputer is always faster or more accurate.

## Reproduce

Create and activate a clean virtual environment, then run:

```bash
python -m pip install faiss-imputer==0.2.0 scikit-learn==1.9.0 numpy==2.5.2 faiss-cpu==1.15.0
python benchmarks/benchmark_imputers.py
```

The script writes a fresh report and JSON file to `benchmark_outputs/`. The committed [raw result](../../benchmarks/results/v0.2.0-windows-py3.12.json) is the exact input for the tables below.

## Method

- Correlated synthetic numeric data, standardized from complete training data.
- In the controlled accuracy, parity, and runtime sections, complete training rows are supplied to every imputer and missing values are introduced only in held-out test rows.
- 5 uniform neighbors; Faiss uses exact `Flat` L2 search.
- Accuracy uses 5 seeds, 5,000 train rows, 500 test rows, 20 features, and 20% missingness.
- Timing is the median of 7 runs with 300 test rows. Method order is rotated, the same test matrix and mask are reused across train sizes, and larger training sets extend smaller ones by prefix.
- Every test row has exactly four missing values. `fixed` means one shared pattern, `eight` means eight controlled patterns, and `random` means each row independently chooses four missing columns.

## Native behavior with incomplete fitting data

The fitting matrix also has 10% independently missing cells. FaissImputer uses only the remaining complete rows as donors, while KNNImputer can use partially observed rows.
To isolate that donor-pool policy, this synthetic experiment standardizes from the complete training truth before cells are hidden; it is not an end-to-end preprocessing benchmark.

## Scope

The controlled sections isolate numerical imputation with complete training donors. They do not establish results for every dataset, hardware configuration, or missing-data mechanism. The separate incomplete-fitting-data section deliberately compares each implementation's native donor policy; there, KNNImputer and FaissImputer 0.2.0 use different donor pools and should not be interpreted as the same algorithm with different search engines.
